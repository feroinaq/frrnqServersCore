# frrnqServersCore

**Версия 1.2 · Minecraft 1.12.2 · Forge 14.23.5.2860 · Java 8**

Мод для командной игры на сервере. Администратор задаёт правила высоты, запас жизней и точки команд, настраивает пополняемые склады и вручную размещает AirDrop. Игроки видят остаток жизней и получают события снабжения прямо в игре.

## Установка и управление

1. Поместите файл релиза `frrnqServersCore-1.2.jar` в папку `mods` сервера и каждого клиента Forge. Для сборки из исходников на Windows используйте `.\gradlew.bat build` с Java 8. Готовый JAR находится в `build/libs/`.
2. Запустите сервер и подключитесь оператором с уровнем прав 2 или выше. Введите `/fcore world info` для проверки. Обычным игрокам команды для HUD и уведомлений не нужны.
3. Команды ниже приведены для игрового чата. В консоли опустите начальный слеш. Редакторы, выбор сундука прицелом и выдача AirDrop требуют присутствия оператора в игре. Угловые скобки обозначают заменяемый аргумент.

## WorldRules

**Правила высоты.** По умолчанию оба правила включены в основном мире (измерение 0). Ниже Y=50 разрешена установка только ванильных лестниц. На Y=50 строительство уже разрешено. Выше Y=120 игрок защищён от атак других игроков, включая их стрелы. Высота определяется по жертве. Пороги меняются командами, измерение и переключатели — в config/frrnqserverscore-worldrules.cfg.

| Команда | Как пользоваться | Пример |
|---|---|---|
| `/fcore world info` | Показать действующие правила. | — |
| `/fcore world buildmin <Y>` | Задать нижнюю границу строительства (0–255). | `/fcore world buildmin 50` |
| `/fcore world pvpmax <Y>` | Задать последнюю высоту, на которой разрешён PvP (0–255). | `/fcore world pvpmax 120` |

## DeathLimit

**Жизни и возрождение.** Игрок начинает с 5 жизнями по умолчанию. Сервер списывает одну за смерть. Счётчик и шкала слева вверху показывают остаток и максимум, при потере вспыхивают красным, при нуле появляется «ВЫБЫЛ». F1 скрывает HUD. При нуле игрок после смерти попадает в точку выбывших, если она задана и безопасна. Режим игры сохраняется.

| Команда | Как пользоваться | Пример |
|---|---|---|
| `/fcore deaths setlimit <лимит>` | Установить общий максимум (1–100). Снижение обрезает излишек, повышение само по себе не возвращает жизни. | `/fcore deaths setlimit 5` |
| `/fcore deaths setspawn <x> <y> <z>` | Задать безопасную точку выбывших в основном мире. Используйте целые координаты и Y от 1 до 254. | `/fcore deaths setspawn 100 70 200` |
| `/fcore deaths info <ник>` | Посмотреть жизни игрока онлайн. | `/fcore deaths info Steve` |
| `/fcore deaths setplayer <ник> <жизни>` | Назначить игроку онлайн остаток от 0 до текущего максимума. | `/fcore deaths setplayer Steve 2` |
| `/fcore deaths reset <ник>` | Восстановить игроку онлайн текущий максимум жизней. | `/fcore deaths reset Steve` |

## TeamSpawn

**Команды игроков.** При оставшихся жизнях действительная кровать имеет приоритет. Если кровати нет, мод ищет безопасное место рядом с точкой команды. Если подходящей точки нет, сохраняется обычное возрождение. Вход на сервер сам по себе не переносит игрока.

Ожидающий ник закрепляется за фактически вошедшим профилем. Если его UUID уже состоит в другой команде, сервер оставляет конфликт администратору и пишет о нём в лог.

| Команда | Как пользоваться | Пример |
|---|---|---|
| `/fcore team create <команда>` | Создать команду. Имя до 32 символов из латинских букв, цифр, дефиса и подчёркивания. | `/fcore team create red` |
| `/fcore team spawn <команда> <x> <y> <z>` | Назначить точку в основном мире (Y 1–254). Нужны твёрдый пол, свободное место и безопасное окружение. | `/fcore team spawn red 10 65 20` |
| `/fcore team add <команда> <ник1;ник2>` | Добавить одного или нескольких игроков. Никнеймы разделяются точкой с запятой без пробелов. Известный игрок привязывается по UUID, неизвестное имя ожидает первого входа без учёта регистра. | `/fcore team add red Steve;Alex` |
| `/fcore team list` | Вывести команды. | — |
| `/fcore team info <команда>` | Посмотреть точку команды, подтверждённых и ожидающих участников. | `/fcore team info red` |
| `/fcore team start` | Перенести подходящих участников онлайн к точкам их команд и отправить уведомление о начале игры. При хотя бы одной успешной телепортации активируется TeamStatusHUD. Офлайн-игроки пропускаются. | — |
| `/fcore team remove <ник>` | Снять ожидающее назначение или удалить подтверждённого участника. Затем его можно добавить в другую команду. | `/fcore team remove Alex` |

## ResourceChests

**Возобновляемые ресурсы.** Получите блок ванильной командой /give @p frrnqserverscore:resource_chest 1 и установите его. ПКМ открывает 27 игровых слотов. Для команд chest встаньте в пределах 6 блоков и наведите прицел на сундук. В редакторе возьмите стопку на курсор и нажмите ЛКМ по ячейке образца. ПКМ по образцу открывает шанс (0–100 %) и диапазон количества, Shift+ЛКМ удаляет образец. Сохраните параметры. При обновлении старое содержимое заменяется, для каждого образца шанс проверяется отдельно.

Таймер по умолчанию включён с интервалом 6 минут. Для каждого цикла выбирается одна случайная локация с привязанными сундуками. За минуту до обновления и после него игроки онлайн видят название локации и слышат сигнал. Пока сервер выключен, отсчёт стоит.

| Команда | Как пользоваться | Пример |
|---|---|---|
| `/fcore resource chest edit` | Открыть редактор образцов выбранного сундука. | — |
| `/fcore resource chest refill` | Немедленно сгенерировать лут в выбранном сундуке по его образцам. | — |
| `/fcore resource location create <имя>` | Создать локацию. Имя до 48 букв, цифр, дефисов или подчёркиваний, регистр не различается. | `/fcore resource location create Depot` |
| `/fcore resource chest bind <локация>` | Привязать выбранный сундук в основном мире к существующей локации. | `/fcore resource chest bind Depot` |
| `/fcore resource chest unbind` | Отвязать выбранный сундук. Для переноса затем выполните bind с другим именем. | — |
| `/fcore resource location list` | Показать локации и количество привязок. | — |
| `/fcore resource location info <имя>` | Посмотреть координаты сундуков, состояние загрузки и сведения о цикле. | `/fcore resource location info Depot` |
| `/fcore resource location refresh <имя>` | Обновить всю локацию вручную. Для выгруженных сундуков обновление применяется при загрузке. | `/fcore resource location refresh Depot` |
| `/fcore resource location delete <имя>` | Удалить локацию и её привязки. Установленные сундуки остаются на месте. | `/fcore resource location delete Depot` |
| `/fcore resource timer info` | Проверить интервал, выбранную локацию и оставшееся время. | — |
| `/fcore resource timer set <минуты>` | Задать интервал 2–120 минут и сбросить текущий цикл. Остановленный таймер останется выключенным. | `/fcore resource timer set 6` |
| `/fcore resource timer start` | Включить автообновление и начать новый цикл. | — |
| `/fcore resource timer stop` | Остановить автообновление и сбросить текущий цикл. | — |

## AirDrop

**Подготовленные тайники.** Шаблон хранит 27 образцов вместе с количеством, metadata и NBT. В редакторе ЛКМ копирует стопку с курсора, ПКМ очищает слот. Предмет AirDrop выдаётся по одному. При установке оператором сервер копирует актуальное содержимое шаблона в отдельный сундук. Последующие правки шаблона влияют только на будущие установки.

После успешной установки все онлайн-игроки получают панель и звуковой сигнал без координат. Ориентир — бирюзовый луч в загруженном чанке. В Survival разбейте сундук, чтобы забрать содержимое. При взрыве лут также выпадает, при удалении игроком в Creative — исчезает. Сундук не открывается, воронка не забирает лут, шёлковое касание не возвращает блок.

| Команда | Как пользоваться | Пример |
|---|---|---|
| `/fcore airdrop template create <имя>` | Создать пустой шаблон. Имена до 48 букв, цифр, дефисов или подчёркиваний, без различия регистра. | `/fcore airdrop template create military` |
| `/fcore airdrop template edit <имя>` | Открыть игровой редактор. Верните исходную стопку с курсора в свой инвентарь после копирования. | `/fcore airdrop template edit military` |
| `/fcore airdrop template info <имя>` | Проверить число заполненных слотов. | `/fcore airdrop template info military` |
| `/fcore airdrop template list` | Показать все шаблоны мира. | — |
| `/fcore airdrop give <шаблон>` | Получить подготовленный сундук в свободный слот своего инвентаря. Шаблон должен содержать хотя бы один образец. | `/fcore airdrop give military` |
| `/fcore airdrop template delete <имя>` | Удалить шаблон. Выданные по нему, но ещё не установленные сундуки станут непригодны даже после создания одноимённого шаблона. | `/fcore airdrop template delete military` |

## TeamStatusHUD

После успешного `/fcore team start`, когда телепортирован хотя бы один участник, под HUD жизней появляется панель **«КОМАНДЫ»**. В строке каждой команды показаны цветной кружок, название и число участников, у которых остались жизни.

- Офлайн-участники с оставшимися жизнями продолжают учитываться.
- Ожидающие назначения по никнейму учитываются до первого входа. После подтверждения используется UUID игрока.
- При потере последней жизни счётчик уменьшается. Команда с нулём участников скрывается, а после восстановления жизней возвращается на своё место.
- Порядок соответствует сохранённому порядку создания. Цвет назначается сервером один раз и сохраняется после перезапуска вместе с состоянием активности HUD.
- Новые игроки получают актуальный список при входе. HUD учитывает GUI Scale и скрывается клавишей F1.

Отдельная команда включения HUD не требуется. Повторный `team start` выполняет существующую телепортацию, поэтому используйте его, когда готовы переместить игроков. Для проверки данных подойдут `/fcore team info <команда>` и `/fcore deaths info <ник>`.

## WorldBorderNotifications

Управляйте стандартной границей мира ванильными командами Minecraft. Мод отслеживает изменения границы основного мира и показывает уведомления всем онлайн-игрокам.

| Команда Minecraft | Действие | Пример |
|---|---|---|
| `/worldborder center <x> <z>` | Задать центр границы. | `/worldborder center 0 0` |
| `/worldborder set <размер> [секунды]` | Установить размер или начать переход к нему. Размер — длина стороны границы в блоках. | `/worldborder set 1000 120` |
| `/worldborder get` | Посмотреть текущий размер. | — |

Например, чтобы сузить границу с 2000 до 1000 блоков за две минуты, выполните в основном мире:

```text
/worldborder set 2000
/worldborder set 1000 120
```

В начале игроки получают сообщение **«ВНИМАНИЕ! БАРЬЕР»** на 7 секунд с оставшимся временем перехода и тревожным сигналом. После достижения цели появляется **«СУЖЕНИЕ ЗАВЕРШЕНО»** на 5 секунд с отдельным звуком. Мгновенное уменьшение сопровождается сообщением о завершении. При расширении уведомления о сужении не отправляются. Загрузка сохранённого сужения не повторяет сигнал о начале.

За пределами текущей ванильной границы вверху по центру отображается **«ВЫ ЗА ПРЕДЕЛАМИ БАРЬЕРА!»**. Проверяются координаты X/Z, высота и буфер урона на предупреждение не влияют. При возвращении внутрь оно исчезает. F1 скрывает панель. Звуки учитывают настройки громкости клиента.

## Уведомление о начале игры

Команда `/fcore team start` также отправляет онлайн-игрокам панель **«ИГРА НАЧАЛАСЬ!»** на 7 секунд с музыкальным сигналом. Панель появляется во время обычной игры и сохраняет управление персонажем. TeamStatusHUD активируется при наличии успешной телепортации.

## Сохранение и особенности интерфейса

Данные хранятся в каталоге мира.

| Данные | Расположение |
|---|---|
| Жизни и точка выбывших | `data/frrnqserverscore_death.dat` |
| Команды, участники, ожидающие назначения, цвета и активность HUD | `data/frrnqserverscore_teams.dat` |
| Локации ResourceChests и состояние таймера | `data/frrnqserverscore_resource_locations.dat` |
| Шаблоны AirDrop | `data/frrnqserverscore_airdrop_templates.dat` |
| Содержимое установленных сундуков | NBT TileEntity в чанках мира |
| Граница мира | Ванильные данные сохранения мира |

Старые команды получают цвет автоматически при загрузке. Их порядок берётся из сохранённого списка TeamSpawn. Палитра содержит 12 оттенков, после её исчерпания цвета могут повторяться.

При большом числе команд панель уменьшается по доступной высоте, а длинные названия обрезаются перед счётчиком. Общая панель событий показывает последнее полученное уведомление. Лучи AirDrop видны в пределах загруженных чанков и дальности рендеринга.
