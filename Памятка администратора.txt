frrnqServersCore — памятка администратора
Minecraft 1.12.2, Forge 14.23.5.2860, Java 8

Один и тот же JAR положи в mods на сервере и у игроков. Войди под OP 2+.
Команды ниже можно копировать в игровой чат. Замени Steve и Alex на свои ники,
red — на имя команды, Depot — на локацию, military — на шаблон.
Координаты в примерах замени координатами безопасных площадок своего мира.

Порядок подготовки игры
1. Проверь высоты и выставь число жизней. Назначь точку выбывших.
2. Создай команды, укажи точки и добавь игроков. Выполни team start в момент старта.
3. Поставь ресурсный сундук, настрой образцы, создай локацию и привяжи сундук.
4. Для AirDrop создай и заполни шаблон, выдай себе сундук и установи его вручную.

1. ПРАВИЛА ВЫСОТЫ

По умолчанию оба правила включены в основном мире (измерение 0). Ниже Y=50 разрешена установка только ванильных лестниц. На Y=50 строительство уже разрешено. Выше Y=120 игрок защищён от атак других игроков, включая их стрелы. Высота определяется по жертве. Пороги меняются командами, измерение и переключатели — в config/frrnqserverscore-worldrules.cfg.

/fcore world info
    Показать действующие правила.

/fcore world buildmin 50
    Задать нижнюю границу строительства (0–255).

/fcore world pvpmax 120
    Задать последнюю высоту, на которой разрешён PvP (0–255).

2. ЖИЗНИ И ВОЗРОЖДЕНИЕ

Игрок начинает с 5 жизнями по умолчанию. Сервер списывает одну за смерть. Счётчик и шкала слева вверху показывают остаток и максимум, при потере вспыхивают красным, при нуле появляется «ВЫБЫЛ». F1 скрывает HUD. При нуле игрок после смерти попадает в точку выбывших, если она задана и безопасна. Режим игры сохраняется.

/fcore deaths setlimit 5
    Установить общий максимум (1–100). Снижение обрезает излишек, повышение само по себе не возвращает жизни.

/fcore deaths setspawn 100 70 200
    Задать безопасную точку выбывших в основном мире. Используйте целые координаты и Y от 1 до 254.

/fcore deaths info Steve
    Посмотреть жизни игрока онлайн.

/fcore deaths setplayer Steve 2
    Назначить игроку онлайн остаток от 0 до текущего максимума.

/fcore deaths reset Steve
    Восстановить игроку онлайн текущий максимум жизней.

3. КОМАНДЫ ИГРОКОВ

При оставшихся жизнях действительная кровать имеет приоритет. Если кровати нет, мод ищет безопасное место рядом с точкой команды. Если подходящей точки нет, сохраняется обычное возрождение. Вход на сервер сам по себе не переносит игрока.

Ожидающий ник закрепляется за фактически вошедшим профилем. Если его UUID уже состоит в другой команде, сервер оставляет конфликт администратору и пишет о нём в лог.

/fcore team create red
    Создать команду. Имя до 32 символов из латинских букв, цифр, дефиса и подчёркивания.

/fcore team spawn red 10 65 20
    Назначить точку в основном мире (Y 1–254). Нужны твёрдый пол, свободное место и безопасное окружение.

/fcore team add red Steve;Alex
    Добавить одного или нескольких игроков. Никнеймы разделяются точкой с запятой без пробелов. Известный игрок привязывается по UUID, неизвестное имя ожидает первого входа без учёта регистра.

/fcore team list
    Вывести команды.

/fcore team info red
    Посмотреть точку команды, подтверждённых и ожидающих участников.

/fcore team start
    Перенести подходящих участников онлайн к точкам их команд. Офлайн-игроки пропускаются.

/fcore team remove Alex
    Снять ожидающее назначение или удалить подтверждённого участника. Затем его можно добавить в другую команду.

4. ВОЗОБНОВЛЯЕМЫЕ РЕСУРСЫ

Получите блок ванильной командой /give @p frrnqserverscore:resource_chest 1 и установите его. ПКМ открывает 27 игровых слотов. Для команд chest встаньте в пределах 6 блоков и наведите прицел на сундук. В редакторе возьмите стопку на курсор и нажмите ЛКМ по ячейке образца. ПКМ по образцу открывает шанс (0–100 %) и диапазон количества, Shift+ЛКМ удаляет образец. Сохраните параметры. При обновлении старое содержимое заменяется, для каждого образца шанс проверяется отдельно.

Таймер по умолчанию включён с интервалом 6 минут. Для каждого цикла выбирается одна случайная локация с привязанными сундуками. За минуту до обновления и после него игроки онлайн видят название локации и слышат сигнал. Пока сервер выключен, отсчёт стоит.

/fcore resource chest edit
    Открыть редактор образцов выбранного сундука.

/fcore resource chest refill
    Немедленно сгенерировать лут в выбранном сундуке по его образцам.

/fcore resource location create Depot
    Создать локацию. Имя до 48 букв, цифр, дефисов или подчёркиваний, регистр не различается.

/fcore resource chest bind Depot
    Привязать выбранный сундук в основном мире к существующей локации.

/fcore resource chest unbind
    Отвязать выбранный сундук. Для переноса затем выполните bind с другим именем.

/fcore resource location list
    Показать локации и количество привязок.

/fcore resource location info Depot
    Посмотреть координаты сундуков, состояние загрузки и сведения о цикле.

/fcore resource location refresh Depot
    Обновить всю локацию вручную. Для выгруженных сундуков обновление применяется при загрузке.

/fcore resource location delete Depot
    Удалить локацию и её привязки. Установленные сундуки остаются на месте.

/fcore resource timer info
    Проверить интервал, выбранную локацию и оставшееся время.

/fcore resource timer set 6
    Задать интервал 2–120 минут и сбросить текущий цикл. Остановленный таймер останется выключенным.

/fcore resource timer start
    Включить автообновление и начать новый цикл.

/fcore resource timer stop
    Остановить автообновление и сбросить текущий цикл.

5. ПОДГОТОВЛЕННЫЕ ТАЙНИКИ

Шаблон хранит 27 образцов вместе с количеством, metadata и NBT. В редакторе ЛКМ копирует стопку с курсора, ПКМ очищает слот. Предмет AirDrop выдаётся по одному. При установке оператором сервер копирует актуальное содержимое шаблона в отдельный сундук. Последующие правки шаблона влияют только на будущие установки.

После успешной установки все онлайн-игроки получают панель и звуковой сигнал без координат. Ориентир — бирюзовый луч в загруженном чанке. В Survival разбейте сундук, чтобы забрать содержимое. При взрыве лут также выпадает, при удалении игроком в Creative — исчезает. Сундук не открывается, воронка не забирает лут, шёлковое касание не возвращает блок.

/fcore airdrop template create military
    Создать пустой шаблон. Имена до 48 букв, цифр, дефисов или подчёркиваний, без различия регистра.

/fcore airdrop template edit military
    Открыть игровой редактор. Верните исходную стопку с курсора в свой инвентарь после копирования.

/fcore airdrop template info military
    Проверить число заполненных слотов.

/fcore airdrop template list
    Показать все шаблоны мира.

/fcore airdrop give military
    Получить подготовленный сундук в свободный слот своего инвентаря. Шаблон должен содержать хотя бы один образец.

/fcore airdrop template delete military
    Удалить шаблон. Выданные по нему, но ещё не установленные сундуки станут непригодны даже после создания одноимённого шаблона.
